## Про гру
**«Хрестики-нулики» — гра для двох гравців (людина проти людини) на полі 3×3. Перемагає той, хто першим вибудує в ряд три свої символи.**

---

## Правила
- Поле 3×3.
- Один гравець грає хрестиками (`X`), інший — нуликами (`O`).
- Гравці ходять по черзі, натискаючи на вільну клітинку.
- Зайняту клітинку обрати не можна.
- Перемагає той, хто першим збере три свої символи в ряд: по горизонталі, вертикалі або діагоналі.
- Якщо всі клітинки заповнені й ніхто не виграв — нічия.

## Як грати
1. Запустіть гру.
2. Першим ходить гравець з хрестиками (`X`).
3. Натисніть на вільну клітинку, щоб поставити символ.
4. Гравці ходять по черзі.
5. Гра закінчується, коли хтось збере три символи в ряд або всі клітинки будуть заповнені.
